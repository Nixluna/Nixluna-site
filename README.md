# Nixluna

Projet e-commerce premium basé sur Next.js et TailwindCSS.

> Ce dépôt contient la version de base du site Nixluna (version démo prête à déployer sur Vercel).

## Structure
- Framework : Next.js
- Style : TailwindCSS (thème luxe bleu nuit, or champagne, blanc neige)
- Objectif : boutique optimisée SEO + tunnel de vente / affiliés
- Hébergement : Vercel (front) + Cloudways (backend optionnel)

## Étapes suivantes
1. Connecter ce dépôt à Vercel.
2. Déployer la version démo.
3. Ajouter les pages Produits, Checkout et Affiliation.
